Original project source is offered under the MIT license in LICENSE. External dependencies are installed separately and retain their licenses:

- Python — Python Software Foundation license
- .NET / WPF — MIT and associated distribution notices
- NumPy — BSD-style license
- OpenCV — Apache 2.0 for current releases, with bundled component notices
- Matplotlib — Matplotlib license and dependency notices

No external JavaScript library, font or CDN is needed by the viewer. Research datasets and fitted research model assets are not redistributed in this repository. Packaging installed dependencies requires retaining their actual distribution notices; the source portfolio's license does not replace them.
